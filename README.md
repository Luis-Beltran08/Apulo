# Casa-Lote en Apulo, Cundinamarca

> 🔬 **Desarrollado por código_con_ciencia -3C-**

Sitio web profesional para la venta de una casa-lote ubicada en el casco urbano de Apulo, Cundinamarca. Diseñado para presentar la propiedad de manera clara y atractiva, enfatizando sus beneficios como opción de descanso o inversión turística.

## 🏠 Descripción de la Propiedad

- **Ubicación**: Casco urbano de Apulo, Cundinamarca
- **Área del lote**: 596 m²
- **Área construida**: 120 m²
- **Clima**: Cálido, aproximadamente 28°C
- **Distancia a Bogotá**: ~101 km por carretera
- **Servicios**: Agua, energía, gas, alcantarillado e internet disponible
- **Estado legal**: Sucesión en proceso avanzado
